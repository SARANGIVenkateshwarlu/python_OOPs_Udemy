Here are the Top 20 OOP Interview Questions in Python with Clear Answers & Explanations ✅
✅ 1. What is Object-Oriented Programming (OOP)?

Answer:
OOP is a programming paradigm that organizes code using classes and objects.

Purpose:

    Reusability
    Maintainability
    Security
    Modularity

✅ 2. What are the four pillars of OOP?
1️⃣ Encapsulation

Wrapping data and methods into a single unit (class) and restricting direct access.
2️⃣ Abstraction

Hiding internal implementation and showing only necessary details.
3️⃣ Inheritance

One class acquiring properties of another class.
4️⃣ Polymorphism

Same method name behaving differently for different objects.
✅ 3. Difference Between Class and Object
Class	Object
Blueprint	Instance of class
Logical entity	Physical entity
No memory allocated	Memory allocated

Example:
python

class Car:  # Class
    pass

c1 = Car()  # Object

✅ 4. What is __init__()?

It is a constructor method automatically called when an object is created.
python

class Person:
    def __init__(self, name):
        self.name = name

Used to initialize object attributes.
✅ 5. What is Encapsulation?

Binding data and methods together and restricting direct access.
python

class Bank:
    def __init__(self):
        self.__balance = 1000   # Private variable

✅ Achieved using:

    _protected
    __private

✅ 6. What is Abstraction?

Hiding internal details and exposing only functionality.

Implemented using abc module.
python

from abc import ABC, abstractmethod

class Shape(ABC):
    @abstractmethod
    def area(self):
        pass

✅ 7. What is Inheritance?

Allows one class to inherit properties of another.

Types:

    Single
    Multiple
    Multilevel
    Hierarchical

python

class Parent:
    pass

class Child(Parent):
    pass

✅ 8. What is Polymorphism?

Same function name with different behavior.

Example:
python

class Dog:
    def sound(self):
        print("Bark")

class Cat:
    def sound(self):
        print("Meow")

✅ 9. Method Overriding vs Overloading
Overriding

Child class redefines parent method.
Overloading

Same method name with different parameters (Python handles using default arguments).
✅ 10. What is super()?

Used to call parent class methods.
python

class Child(Parent):
    def __init__(self):
        super().__init__()

✅ 11. Access Modifiers in Python
Modifier	Syntax	Meaning
Public	var	Accessible everywhere
Protected	_var	Internal use
Private	__var	Not directly accessible
✅ 12. Difference Between @staticmethod and @classmethod
Static Method	Class Method
No access to class or instance	Access to class via cls
No self	Uses cls
✅ 13. Instance vs Class Variables
Instance Variable	Class Variable
Unique per object	Shared among all objects
✅ 14. What are Magic Methods?

Special methods starting and ending with __.

Examples:

    __init__
    __str__
    __len__

Used to customize object behavior.
✅ 15. What is Multiple Inheritance?

A class inheriting from more than one class.
python

class A:
    pass

class B:
    pass

class C(A, B):
    pass

Diamond Problem:

When two parent classes have same method → Python solves using MRO.
✅ 16. What is MRO?

Method Resolution Order determines order in which methods are searched.
python

ClassName.mro()

Python uses C3 Linearization Algorithm.
✅ 17. What is an Abstract Class?

A class that cannot be instantiated and contains abstract methods.
python

from abc import ABC

Used for blueprint design.
✅ 18. Composition vs Inheritance
Inheritance	Composition
IS-A relationship	HAS-A relationship
Reuse via extending	Reuse via object inside class

Example:

    Car IS-A Vehicle (Inheritance)
    Car HAS-A Engine (Composition)

✅ 19. What is Data Hiding?

Restricting access to internal data.

In Python:

    True private does not exist.
    Name mangling is used: __var

✅ 20. Advantages & Disadvantages of OOP
✅ Advantages:

    Code reuse
    Security
    Easy maintenance
    Modularity

❌ Disadvantages:

    Complex design
    More memory usage
    Slower execution sometimes

✅ Bonus Concepts
Duck Typing

"If it walks like a duck…" → Object type doesn't matter, behavior matters.
Operator Overloading

Using magic methods like:
python

__add__()

is vs ==

    is → memory location
    == → value comparison
